## Этап 1. Парсер CSV для книг (задание на паре)

**Дата и инструмент:** ДД.ММ.ГГГГ — ВСТАВИТЬ НАЗВАНИЕ НЕЙРОСЕТИ

**Промпт:**
> Вот описание лабораторной №7 (Lab7.md): чтение CSV. Сделай основное задание: файл books.csv с 50+ строками (с кавычками, запятыми в названиях и ошибками: недостаточно полей, нечисловой год, пустой ISBN, дубликаты ISBN); парсер с учётом кавычек и чтением через BufferedReader; тот же парсер через Files.readAllLines() и Stream API; статистику (всего строк, успешно, ошибки по типам, дубликаты); запись результата в books_clean.csv. Maven, Java 17+, SLF4J.

**Результат ИИ:** ассистент подготовил `books.csv` (58 строк данных и заголовок), класс `CsvLineParser` (разбиение строки по правилам RFC 4180), общий загрузчик `CsvLoader` с двумя методами (`loadWithBufferedReader`, `loadWithStreams`), `BookMapper` с правилами проверки, `CsvStatistics`, `CsvWriter` и `Main` с выводом статистики и сравнением подходов.

**Анализ результата:**
- Вместо регулярного выражения из методички использован собственный разбор строки по символам: выражение из методички не обрабатывает экранированные кавычки (`""`), а собственный парсер учитывает и запятые, и удвоенные кавычки внутри поля.
- Оба способа чтения используют один и тот же разбор строки, поэтому результаты совпадают; в `Main` это проверяется сравнением списков.
- В файле предусмотрены ошибки каждого типа: недостаточно полей (3), слишком много полей (1, запятая в названии без кавычек), нечисловой год (2), пустой ISBN (4) и дубликаты ISBN (2). Статистика в консоли должна совпасть с этими числами. [ПРОВЕРИТЬ после запуска.]
- Поля, взятые в кавычки, и поля без кавычек читаются одинаково; в `books_clean.csv` кавычки добавляются только там, где они нужны (запятая или кавычка внутри значения).
- Сравнение: `BufferedReader` читает по одной строке и экономит память, а `Files.readAllLines()` короче, но загружает весь файл. Время в консоли ориентировочное, потому что первый замер включает прогрев JVM.

**Внесённые изменения:** открыт проект `lab07-csv-io`, файлы CSV лежат в `src/main/resources`, результат записывается в папку `output`. [ДОПИСАТЬ, если что-то меняла сама.]
