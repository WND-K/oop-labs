## Этап 1. Исключения, валидация, репозиторий и логирование (задание на паре)

**Дата и инструмент:** ДД.ММ.ГГГГ — ВСТАВИТЬ НАЗВАНИЕ НЕЙРОСЕТИ

**Промпт:**
> Вот описание лабораторной №6 (Lab6.md): исключения и логирование. Сделай основное задание на классе Book: checked-исключение BookNotFoundException и unchecked-исключение InvalidBookDataException (по два конструктора, в том числе с причиной); валидацию в сеттерах Book с логированием ERROR; BookRepository с логированием INFO и WARN и выбрасыванием BookNotFoundException; подключение SLF4J + Logback (консоль и файлы); код с try-catch-finally и try-with-resources для чтения и записи файлов. Maven, Java 17+, Javadoc.

**Результат ИИ:** ассистент создал два класса исключений, класс `Book` с валидацией в сеттерах, `BookRepository` (`save`, `findById`, `delete`, `findAll`), `pom.xml` с зависимостями SLF4J и Logback, `logback.xml` (консоль, общий файл, отдельный файл ошибок), `BookFileService` (запись и загрузка книг через try-with-resources), `LogFileService` (чтение журнала через try-catch-finally) и `Main` с демонстрацией.

**Анализ результата:**
- Оба класса исключений наследуются правильно (`Exception` и `RuntimeException`), у каждого есть конструкторы с сообщением и с сообщением и причиной, оба вызывают `super(...)`.
- В примере из методички (раздел 2.7) `findById` бросает checked-исключение без `throws`, что не компилируется; в коде метод объявлен с `throws BookNotFoundException`, а вызывающий код обрабатывает исключение через try-catch.
- Сеттеры `Book` сначала пишут ERROR в лог, а потом выбрасывают `InvalidBookDataException`.
- Репозиторий пишет INFO при успешных операциях и WARN при обращении к несуществующей книге.
- Для файловых операций использован try-with-resources: поток закрывается автоматически, а в `LogFileService` для сравнения оставлен классический try-catch-finally.
- Вывод в консоли и в файле `logs/application.log` содержит сообщения уровней INFO, WARN и ERROR. [ПРОВЕРИТЬ после запуска, в том числе появление папки `logs`.]

**Внесённые изменения:** открыт проект `lab06-exceptions-logging`, Maven загрузил зависимости. [ДОПИСАТЬ, если что-то меняла сама.]
